# 4.2.1-tipo-full-folder — Novo tipo full-folder com rotação

- **Origem:** [[pop/roadmap/4-robustez-e-full-folder|Phase 4.2]]
- **Plano:** [[4.2.1-tipo-full-folder.plan]] · **Aprovação:** [[4.2.1-tipo-full-folder.approval]] · **Verificação:** [[4.2.1-tipo-full-folder.verify]]

## O quê

Novo `type: full-folder` no backups.json: funciona como o compacted, mas sem compactação — copia o folder para o remoto como pasta datada (`<base>-<AAAAMMDD-HHMMSS>/`), aplica `max_backups` excluindo a pasta mais antiga quando excedido; validação, TUI, restore e README acompanham o novo tipo.

## Por quê

O usuário quer backup versionado sem o custo de compactação: o compacted agora exige streaming tar+gzip, e há casos em que a cópia direta da pasta datada é o comportamento desejado, mantendo histórico com rotação.
