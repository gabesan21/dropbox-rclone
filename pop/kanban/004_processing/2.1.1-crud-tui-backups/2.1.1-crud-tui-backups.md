# 2.1.1-crud-tui-backups — TUI de gestão do backups.json

- **Origem:** [[pop/roadmap/2-interface-e-servico|Phase 2.1]] — *siga para ver as tasks irmãs da phase*.
- **Plano:** [[2.1.1-crud-tui-backups.plan]] · **Verificação:** [[2.1.1-crud-tui-backups.verify]]

## O quê

Subcomando `manage` no mesmo binário Go: TUI que lista as entradas do `backups.json`, adiciona e edita via formulário huh com validação, remove com confirmação e persiste o arquivo.

## Por quê

O JSON hoje só é editável na mão; a TUI elimina erro de sintaxe e de schema na operação em servidor remoto via SSH.
