# 2.2.1-script-servico-systemd — service.sh com unit e timer

- **Origem:** [[pop/roadmap/2-interface-e-servico|Phase 2.2]] — *siga para ver as tasks irmãs da phase*.
- **Plano:** [[2.2.1-script-servico-systemd.plan]] · **Verificação:** [[2.2.1-script-servico-systemd.verify]]

## O quê

`service.sh` que lê `BACKUP_INTERVAL_MINUTES` do `.env`, gera unit + timer de systemd (nível usuário) e oferece as ações install/enable/disable/status/remove.

## Por quê

É o que faz o motor de backup rodar a cada intervalo no servidor remoto, sem cron editado na mão; instalar de verdade fica no gate humano.
