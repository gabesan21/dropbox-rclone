# TUI, documentação e exemplo

O formulário da TUI ganhou `name` (obrigatório, usado por force/restore) e select de `repeat_cicle` com default `24h`; a lista passa a exibir e filtrar pelo nome, com fallback para o path em entradas legadas, e a descrição de `max_backups` marca que só se aplica a compacted. O README documenta os campos novos, a semântica de slots e a seção de operação manual; o `backups.json` de exemplo segue o novo schema.
