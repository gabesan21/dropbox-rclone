# Criação do install.sh

Criado `install.sh` na raiz do repo, executável, com detecção de distro via `/etc/os-release` e instalação de rclone e Go via `apt`, `pacman` ou `dnf` conforme a família. O script verifica pré-requisitos antes de instalar e valida a instalação ao final.
