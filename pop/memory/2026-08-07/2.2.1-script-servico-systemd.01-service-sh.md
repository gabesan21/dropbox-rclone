# Script de gestão do serviço systemd

`service.sh` gera unit oneshot (WorkingDirectory/ExecStart no binário, EnvironmentFile opcional para o `.env`) e timer (`OnBootSec=2min` + `OnUnitActiveSec` lido de `BACKUP_INTERVAL_MINUTES`, validado como inteiro ≥ 1) em systemd de usuário — sem root no servidor remoto. Todo `systemctl` passa pelo wrapper `run_systemctl`, que ecoa em `DRY_RUN=1`; `SYSTEMD_USER_DIR` sobrescreve o destino e a guarda `BASH_SOURCE` permite sourcear o script em testes. Instalação/habilitação reais ficam no gate humano.
